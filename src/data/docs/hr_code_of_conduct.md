# 员工行为准则与报销制度

## 1. 行为准则
- 遵守国家法律法规与公司各项规章制度，维护公司利益与声誉。
- 诚实守信，禁止弄虚作假、营私舞弊、利益冲突不申报。
- 尊重同事，禁止职场骚扰、歧视与暴力行为。
- 保护商业秘密，离职后仍需履行保密义务。

## 2. 费用报销范围
- 可报销：差旅交通、住宿、业务招待、办公用品、培训费用（经审批）。
- 不可报销：个人消费、罚款、与业务无关的支出。

## 3. 报销流程
1. 在财务系统提交报销单，上传发票原件照片（需清晰、抬头为公司全称）。
2. 部门负责人审批费用合理性。
3. 财务复核发票真伪与合规性。
4. 审批通过后 5 个工作日内打款至工资卡。

## 4. 时限与标准
- 差旅住宿一线城市上限 500 元/晚，其他城市 350 元/晚。
- 业务招待人均不超过 200 元，需注明事由与参与人。
- 当月费用原则上当月报销，最迟不跨季度。

## 5. 违规处理
虚报、伪造发票者，不予报销并视情节给予纪律处分；涉嫌犯罪的移交司法机关。
