# 新员工入职流程

## 1. 入职前（Offer 发放后 3 个工作日内）
- 签署电子劳动合同与保密协议。
- HR 创建员工档案，生成工号（格式：E + 4 位数字，如 E1001）。
- 同步开通邮箱与域账号（见《账号与邮箱开通规范》）。

## 2. 入职第一天
- 携带身份证、学历学位证、银行卡复印件到 HR 处报到。
- 领取工牌、门禁权限，签署《员工手册确认书》。
- IT 部门发放办公电脑（见《IT 设备申领与归还》）。

## 3. 入职第一周
- 参加新员工培训（公司文化、信息安全、合规）。
- 在导师带领下熟悉业务系统与代码仓库权限。
- 30 天内完成试用期目标确认书（KPI/OKR）。

## 4. 转正
- 试用期一般为 3 个月，表现优秀可提前至 2 个月。
- 转正前 7 天由主管发起转正评估，HR 复核后生效。

## 5. 所需材料清单
1. 身份证正反面复印件
2. 学历、学位证书复印件
3. 上家单位离职证明
4. 本人名下银行卡复印件
5. 一寸免冠照片 2 张（或电子版）
