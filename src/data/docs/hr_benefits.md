# 员工福利与社会保障

## 1. 五险一金
- 公司依法为员工缴纳养老保险、医疗保险、失业保险、工伤保险、生育保险及住房公积金。
- 公积金缴存比例为个人 12% + 公司 12%（基数按上年度月平均工资的 60%–300% 核定）。
- 社保公积金基数每年 7 月调整一次。

## 2. 补充商业保险
- 入职即享补充医疗保险，覆盖门诊与住院自费部分（年度上限 2 万元）。
- 可为配偶及子女附加投保（费用自理）。

## 3. 节假日与福利
- 法定节假日按国家规定执行；春节额外给予 3 天带薪福利假。
- 生日当月发放生日礼金 300 元及蛋糕券。
- 每年组织一次免费体检（含家属优惠套餐）。

## 4. 其他关怀
- 餐补：每个工作日 30 元，随工资发放。
- 交通补：外勤岗位每月 200 元。
- 团建经费：部门每季度 200 元/人。
