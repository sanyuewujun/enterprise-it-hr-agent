# IT 设备申领与归还

## 1. 设备标准配置
- 研发岗：笔记本电脑（16G 内存 / 512G 固态）+ 外接显示器 1 台。
- 非研发岗：台式机或笔记本（8G 内存 / 256G 固态）+ 显示器 1 台。
- 外设：键盘、鼠标、耳机按岗位需求申领。

## 2. 申领流程
1. 在 IT 服务台（itsm 系统）提交「设备申领」工单，注明岗位与用途。
2. IT 资产管理员核对标准配置，审批后出库。
3. 员工签收设备并登记资产编号（SN）。
4. 设备绑定至员工工号，纳入资产管理。

## 3. 使用规范
- 公司设备仅用于工作用途，禁止私自安装未授权软件。
- 设备丢失须在 24 小时内报 IT 并说明情况，人为损坏照价赔偿。
- 离职时须归还全部设备，IT 验收后方可办理离职手续。

## 4. 故障与维修
- 硬件故障通过 IT 服务台提交「设备维修」工单。
- 保修期内免费维修；人为损坏由员工承担费用。
- 维修期间可申请备用机。

## 5. 升级与置换
- 设备使用满 3 年可申请置换；性能不足可提前申请，由 IT 评估。
