# VPN 使用指南

## 1. 适用场景
员工在家办公、出差或访问内网系统（如 OA、代码仓库、内部 Wiki）时需使用 VPN。

## 2. 安装与配置
1. 从 IT 门户下载对应客户端（Windows / macOS / 移动端）。
2. 服务器地址：vpn.corp.example.com，端口 443。
3. 使用域账号 + 动态令牌（OTP）登录；首次登录需绑定 Authenticator 应用。
4. 连接模式选择「自动分流」，仅内网流量走隧道。

## 3. 常见故障排查
- **无法连接**：检查网络是否正常；确认 OTP 未过期（30 秒刷新）；尝试切换网络。
- **连接后无法访问内网**：确认目标系统域名正确；执行 `ipconfig /flushdns` 刷新 DNS。
- **频繁掉线**：关闭省电模式对网卡的休眠；联系 IT 检查账号并发数限制。
- **提示证书错误**：确认系统时间准确，重新安装根证书。

## 4. 安全须知
- 禁止将 VPN 账号借给他人使用。
- 离开电脑务必断开 VPN。
- 发现异常流量立即断开并报告信息安全团队。
