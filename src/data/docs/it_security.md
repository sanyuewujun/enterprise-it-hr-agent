# 信息安全规范

## 1. 账号与密码
- 域账号密码长度不少于 12 位，含大小写字母、数字与特殊字符，90 天强制更换。
- 禁止在多个系统复用同一密码；禁止使用生日、工号等弱密码。
- 离开工位须锁屏（Windows: Win+L）。

## 2. 钓鱼邮件防范
- 不点击来源不明的链接与附件；可疑邮件转发至 security@corp.example.com 研判。
- 凡涉及转账、密码、验证码的邮件，须通过电话与发件人二次确认。
- 公司不会通过邮件索要密码或验证码。

## 3. 数据分级
- 机密数据（薪酬、合同、源码）仅限授权人员访问，禁止外发至个人邮箱或网盘。
- 敏感数据外发需经部门负责人审批并登记。
- 离职人员权限在离职当日全部回收。

## 4. 设备与网络
- 公司设备须安装终端安全软件并保持更新。
- 禁止连接未知公共 Wi-Fi 处理机密业务；必要时使用手机热点或 VPN。
- 禁止私自搭建代理、翻墙工具访问外部受限资源。

## 5. 违规处理
违反上述规范者，视情节给予警告、记过直至解除劳动合同；涉嫌违法的移交司法机关。
