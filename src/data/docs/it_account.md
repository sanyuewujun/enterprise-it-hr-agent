# 账号、邮箱与 SSO 开通规范

## 1. 域账号
- 域账号（Active Directory）为员工统一身份，格式：姓名拼音@corp.example.com（如 zhangwei@corp.example.com）。
- 入职当天由 IT 自动创建，初始密码为工号后 6 位 + 大写首字母，首次登录强制修改。
- 域账号用于登录电脑、Wi-Fi、VPN 与内部系统。

## 2. 企业邮箱
- 邮箱与域账号同源，地址同域账号。
- 邮箱容量 50G，支持移动端 Exchange 协议。
- 离职 30 天后邮箱归档并停用。

## 3. 单点登录（SSO）
- OA、HR 系统、IT 服务台、代码仓库均接入 SSO，使用域账号一次登录。
- 首次使用需在 SSO 门户绑定 MFA（动态令牌）。
- 忘记密码可通过 SSO 自助重置（需 MFA 验证）。

## 4. 权限申请
- 业务系统额外权限（如数据库、生产环境）通过 IT 服务台提交「权限申请」工单。
- 遵循最小权限原则，审批链：直属主管 → 系统负责人 → IT。
- 临时权限默认 7 天有效期，到期自动回收。

## 5. 账号重置
- 密码遗忘：通过 SSO 自助重置或联系 IT 服务台核实身份后重置。
- 账号锁定：连续 5 次密码错误触发锁定，30 分钟自动解锁或联系 IT 解锁。
